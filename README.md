# Paris Airbnb Data Analysis & Visualization

## Project Overview
This project processes raw geospatial coordinates and tabular data of Paris Airbnb listings into interactive spatial visualizations.

## Tools Used
- **Python (Pandas, GeoPandas):** Parsing coordinates and preparing geospatial datasets.
- **ArcGIS Online:** Interactive spatial mapping and price cluster visualization.

## Key Features
- **Coordinate Parsing:** Extracted spatial coordinates from raw CSV files to create accurate point geometries.
- **Geospatial Mapping:** Converted tabular location data into structured vector layers.
- **Visualization:** Mapped listing distributions and price clusters across Paris districts in ArcGIS Online.

## How to use
The core processing logic is available in `Paris_Airbnb_Analysis.py`. The final visual results and spatial patterns are documented in the project screenshots.
